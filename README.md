# Raja Das — Personal Portfolio

A responsive dark developer portfolio built with HTML, CSS and JavaScript.

## Files

- `index.html` — portfolio content and structure
- `style.css` — responsive design and animations
- `script.js` — navigation, scroll reveal and project modal

## Before publishing

Replace these placeholders in `index.html`:

- `rd8629040@gamil.com`
- `RAJA DAS`
- GitHub URL
- LinkedIn URL
- Project repository/demo links

## Run locally

Open `index.html` in a browser.

For the best development experience, use VS Code with the Live Server extension.

## Deploy

You can deploy this folder using GitHub Pages, Netlify, Vercel, or another static hosting service.
